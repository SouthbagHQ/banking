Welcome to the southbag security bounty program

The security bounty program is closed because we sent our trained team of untrained kids discovered all our systems are insecure.

all the security problems are as followed

  • everyones password is stored in plain text
  • the delete account button is not a form and can be triggered by anyone
  • the secure portal page has no authentication and can be accessed by anyone
  • the real.html page has a script that sends your credentials to an attacker
  • the chat widget can be used to inject scripts into the page
  • everyones password is the same
  • there is no rate limiting on login attempts
  • there is no input validation
  • there is no HTTPS
  • the optimise.js file causes layout shifts that can be exploited
  • anyone can change anyone's password without knowing the old one
  • anyone can transfer money between accounts without authorization
  • anyone can delete anyone's account and we show the deleted data
  • CORS is set to * on all API endpoints allowing any website to try its luck
  • failed login attempts tell you what the correct password is
